# Капер ИИ — Telegram-бот

Бот читает публичные файлы приложения с GitHub Pages: матчи, коэффициенты, прогнозы и рассчитанные результаты.

- `/today` — матчи по датам и карточки матчей.
- `/rating` — полный рейтинг источников с постраничной навигацией; текущая статистика ИИ и архивная выборка ≥75% показаны раздельно.
- `/express` — экспресс из 3–5 событий с общим коэффициентом не ниже 2.00. Если подходящих матчей и котировок нет, бот сообщает об этом и не подставляет выдуманные значения.

## Кто и когда обновляет публикацию

1. Сборщик прогнозов сайтов запускается ежедневно в 12:00 МСК в репозитории `football-prognozy`.
2. Локальный ИИ формирует мнения на компьютере в 12:00 МСК и отправляет `gpt.json` в GitHub.
3. Бот на Render автоматически публикует ежедневную сводку в 12:30 МСК. Она включает лучший доступный выбор ИИ, экспресс, полный рейтинг источников, отдельную статистику ИИ и результат вчерашнего экспресса.
4. Результаты матчей и рейтинги рассчитываются из `results.json` сборщиком проекта `football-prognozy`. Для экспресса бот сохраняет купон дня и сверяет его исходы с фактическими счетами при следующей публикации. При ставке 1 000 ₽ показывает расчётную выплату и чистый результат.

Рейтинг источников включает все накопленные строки, а в боте открывается страницами по 15 записей. Возвраты показаны отдельно и не входят в процент проходимости.

## Хранение экспрессов

Бот сохраняет дневные купоны в JSON-файле. По умолчанию используется `.express_history.json` рядом с кодом. Путь можно переопределить переменной `EXPRESS_HISTORY_FILE`.

Если файловая система хостинга очищается при перезапуске или новом развёртывании, история экспрессов может сброситься. Для постоянной истории укажите путь к подключённому постоянному хранилищу Render либо подключите внешнее хранилище.

## Настройка Render

- Build command: `pip install -r requirements.txt`
- Start command: `python bot.py`
- Обязательные переменные: `BOT_TOKEN`, `REQUIRED_CHAT`
- Необязательные переменные: `CHANNEL_URL`, `DATA_BASE`, `EXPRESS_HISTORY_FILE`

Токен хранится только в переменной окружения Render. Не добавляйте его в GitHub или переписку.

Бот поднимает health-check на `/`. Для бесплатного веб-сервиса настройте внешний пингер, чтобы Render не переводил сервис в сон. Ежедневный пост отправляется только когда процесс бота запущен и `REQUIRED_CHAT` настроен.

## Локальный запуск

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Windows PowerShell:
# $env:BOT_TOKEN="..."
# $env:REQUIRED_CHAT="@имя_канала"
python bot.py
```

Бот работает через Telegram polling. Для публикации в канал он должен быть добавлен туда администратором с правом отправки сообщений.
